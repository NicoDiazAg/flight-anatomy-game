# Flight Bone Anatomy Game 🦇
This is a browser game that aims to help students learn where essential flight bones are on birds, pterosaurs, and bats, based on the BIOL 150 course taught by Dr. Thomas Jensen at Hobart and William Smith Colleges. I developed it using HTML, CSS, and JavaScript for simplicity.
